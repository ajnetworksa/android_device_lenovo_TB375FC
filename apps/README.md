# Prebuilt Apps for Lenovo TB375FC Device Tree

To keep the device tree clean, the actual `.apk` binary files are not checked into this directory. Before building the ROM, you must download the latest releases of these applications and place them in this folder renamed exactly as defined below.

### 1. Saber (Samsung Notes / Goodnotes Equivalent)
*   **Description**: A premium vector-based handwriting notes app optimized for stylus digitizers (Palm rejection, pressure sensitivity, PDF annotation).
*   **Download**: [Saber GitHub Releases](https://github.com/saber-notes/saber/releases)
*   **File Name**: `Saber.apk`

### 2. PocketPal AI (On-Device Local AI LLM Client)
*   **Description**: A local, open-source client to run lightweight LLMs (like Llama 3, Phi 3, Gemma) entirely offline on your device using llama.cpp.
*   **Download**: [PocketPal AI GitHub Releases](https://github.com/pocketpalai/pocketpal-ai/releases)
*   **File Name**: `PocketPalAI.apk`

### 3. SD Maid SE (Device Care Equivalent)
*   **Description**: The gold-standard open-source Android storage cleaner, app manager, and system optimizer (acts as Device Care).
*   **Download**: [SD Maid SE GitHub Releases](https://github.com/d4rken-org/sdmaid-se/releases)
*   **File Name**: `SDMaidSE.apk`

### 4. WiFiAnalyzer (Samsung Intelligent Wi-Fi / Connectivity Labs Equivalent)
*   **Description**: Advanced network scanner, channel rating utility, access point inspection tool, and signal tester.
*   **Download**: [WiFiAnalyzer GitHub Releases](https://github.com/VREMSoftwareDevelopment/WiFiAnalyzer/releases)
*   **File Name**: `WiFiAnalyzer.apk`

### 5. Brave Browser
*   **Description**: A fast, privacy-focused web browser with native ad-blocking, script protection, and cookie managers.
*   **Download**: [Brave Browser GitHub Releases](https://github.com/brave/brave-browser/releases)
*   **File Name**: `Brave.apk`
